# the ruins: what this profile used to be

Before it was 日月神教, the Sun Moon Divine Sect, this page was a machine.

- [whitebox-os/](whitebox-os/README.md): the machine called tianni (ART3M1S OS),
  as found on 2026-10-24 at commit `a864764`. The page, its drawings, its
  scripts, its old CLAUDE.md and the workflow that rebooted it every Saturday.
  The minesweeper board is sealed: its links no longer open petitions.
- [sun-moon-v1/](sun-moon-v1/README.md): the first page of the Sun Moon Divine
  Sect, as it was at commit `04bff9e`: nine banners, an identity card, the
  steward's mission board and the timetable, before it was cut down to three
  sections. Its formation board is sealed the same way, and every picture it
  did not take along is pinned to that commit.

Nothing here runs, and no script writes to this folder. It is kept verbatim,
so it is exempt from the sect's fiction rules. To see the machine exactly as
it was, browse the repo at
[`a864764`](https://github.com/IdkwhatImD0ing/IdkwhatImD0ing/tree/a8647642983b70c48efd6df7220e6823478ad7a5).
